# Automated Lead Generation & Outreach Engine

This repo contains a scaffold for an automated lead-generation and outreach demo.

Features
- Streamlit UI for input (Business Category + City)
- SerpAPI-based business search
- Website scraper to discover emails and phone numbers
- OpenAI-based personalized email generation
- Storage to Google Sheets (or local CSV fallback)
- Outreach simulation logging

See README.md for setup and usage.
